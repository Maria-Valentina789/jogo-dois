O Jogo da Adivinhação possui regras simples baseadas na lógica de eliminação rápida através de dicas.

-Objetivo: Descobrir o número secreto escolhido aleatoriamente pelo computador.

-Intervalo: O número sorteado está entre 1 e 100.

-Dicas a cada rodada: Se o palpite for incorreto, o sistema avisa se o número secreto é MAIOR ou MENOR que o valor digitado.

-Contagem de palpites: Cada tentativa é registrada para medir o seu desempenho.

-Condição de vitória: O jogo termina assim que você acertar o número exato, exibindo o total de tentativas utilizadas.
